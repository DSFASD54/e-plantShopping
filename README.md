# 🌿 Paradise Nursery - Shopping Application

## Project Overview
Paradise Nursery is a dynamic e-commerce web application built with React and Redux. It allows users to browse houseplants, view product details, add items to a shopping cart, and manage quantities — all with a smooth, responsive UI.

## Features
- **Product Listing** – Plants grouped into categories (e.g., Indoor, Outdoor, Succulents) with thumbnails, names, and prices.
- **Shopping Cart** – Add/remove items, adjust quantities, see subtotals and total.
- **Redux State Management** – Persistent cart state with slice architecture.
- **Navigation** – Navbar with links to Home, Plants, and Cart, plus a dynamic cart badge.

## Technologies Used
- React 18
- Redux Toolkit
- React Router DOM
- CSS3
